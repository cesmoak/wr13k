Race jet skis!

WASD to control.

Build your boost and beat those bots.

4 levels, day/night. Rainbows everywhere. Unicorn skis.


# Implementation Notes

I worked closely with Codex to create this game. I have created jet ski games before, but fitting this one into the code size limit was a fun new challenge.

The handling is arcadey. The rider reacts to the ski as it moves.

The four courses span a full day/night cycle, and the time of day progresses during races. The courses and the opponents both increase in difficultly with each level.

The rules and feel take inspiration from the original Wave Race 64. Pass buoys to gain boost, missing one resets it. Miss too many and you lose the race. Sometimes skipping a buoy on purpose is worth the shortcut.

Leave the title screen running to watch the bots race.

And, of course, full boost lets you ride the rainbow.
